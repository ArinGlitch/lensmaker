## [0:00–0:15] The problem

> "Every app you use ships one frozen interface. Someone designed it months ago for an
> average user who doesn't exist.
>
> So a student opens their inbox and wants to know *am I about to get charged?* A manager
> opens the same inbox and wants *what's blocked on me?* Same screen. Both of them
> fighting it — adding filters, hiding columns, exporting to a spreadsheet just to see
> what they actually came for."

**DEMO:** App open with **Generative UI toggled OFF** — the plain fixed dashboard.
Scroll it slowly. A wall of 85 emails, one boring table.

---

## [0:15–0:30] The idea

> "We asked a different question. What if you didn't adapt to the interface — what if the
> interface was built for your question, the moment you asked it?
>
> This is Lensmaker. There are no dropdowns in this app. No sort buttons. No column
> pickers. They don't exist. You type what you care about, and Gemini builds the screen."

**DEMO:** Flip the toggle **ON**. Type `what's about to charge me?` — a big total and a
timeline assemble. Let it land for a beat.

---

## [0:30–0:50] The theme — Gemini as the I/O module

> "And this is where the theme really lands, because Gemini is doing *both* ends.
>
> On the way **in** — nobody typed this data. We fed it 85 raw, messy emails and Gemini
> read every one and pulled out the structure. Amounts, deadlines, urgency. There's no
> import form anywhere in this app.
>
> On the way **out** — Gemini doesn't just answer. It *chooses the screen*. It picks from
> fifteen block types we built, configures each one, and returns that choice as JSON. Ask
> a different question, you get a structurally different screen."

**DEMO:** Two fast intents back to back —
1. `what are my hard deadlines?` → the timeline **vanishes**, a calendar/rail appears
2. `am I screwed this week?` → a huge one-line **verdict** in colour

Then click **Inspect spec** — show the raw JSON for two seconds. *This is the money shot.*

## Notes for delivery

**The one line that wins it:** *"Take Gemini away and there's no interface left."*
Say it slowly. That's the theme statement and the technical claim in one sentence.

**The best moment is the vanish at 0:30.** Judges need to see one screen *replaced* by a
structurally different one, not filtered. Pause a full second on each so it registers.

**Warm the cache before presenting:** `npm run demo:warm`. Cached responses return in 0ms;
cold is 2.2–5.0s, and four cold calls would eat 20 seconds of a 75-second video.

### If a judge asks about Gemini vs Haiku

"The Gemini provider is fully implemented with native structured output — one env var
switches it. We hit intermittent 503s under load during testing, so the recorded demo runs
on a Bedrock fallback through the same provider interface."

That is a *strength* answer — it shows a real abstraction, not a wrapper.

### Backup answers

- **"How do you stop it hallucinating a component?"** → "It can't. It picks from a fixed
  catalog, every response is schema-validated, and an unknown block type renders nothing."
- **"Couldn't you hardcode this?"** → "The hardcoded version is one click away" — flip the
  ablation toggle off. That is why that switch exists.
